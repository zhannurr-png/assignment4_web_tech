- **Student:** Zhannur Bakyt

## About the Project
This project demonstrates the use of HTML forms, HTML5 form validation, Bootstrap form components, and JavaScript validation.

## Tasks

### Task 0: Simple Contact Form
A basic contact form with Name, Email, and Message fields, labels, and a Submit button.

### Task 1: HTML5 Validation
A contact form with built-in HTML5 validation using attributes such as `required`, `type="email"`, and `maxlength`.

### Task 2: Bootstrap Form Styling
A contact form styled with Bootstrap. Bootstrap Grid is used to arrange the fields responsively. Placeholders and helper text are included.

### Task 3: Bootstrap Validation
A contact form with Bootstrap validation feedback. JavaScript is used to display error and success states for the input fields.

### Task 4: Registration Form
A registration form with First Name, Last Name, Email, Password, Confirm Password, Gender, Hobbies, and Country fields. It includes Submit and Reset buttons, HTML5 validation, Bootstrap feedback, and responsive layout.
